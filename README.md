# Multi-Tenant School Administration Management SaaS Platform

## Project Overview

A cloud-based Multi-Tenant School Administration Management SaaS Platform developed as part of the MCA Major Project.

## Technology Stack

- Laravel 13
- PHP 8.4
- MySQL 8
- Bootstrap 5
- Stancl Tenancy
- Laravel Breeze
- Git & GitHub

## Modules

- School Onboarding
- Multi-Tenant Management
- Student Management
- Attendance Management
- Fee Management
- Examination & Grading
- Role-Based Access Control
- Reports & Analytics
- Audit Logs
