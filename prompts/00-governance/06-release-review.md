# Release Review

## Execution Mode

Audit only. Do not modify files.

## Objective

Determine whether the repository is ready to move to the next phase, demo milestone, deployment simulation, or final MCA submission.

## Authoritative Documents

Read and follow:

- `AGENTS.md`
- `docs/PROJECT_CONSTITUTION.md`
- `docs/PROJECT_GOVERNANCE.md`
- `docs/DEVELOPMENT_ROADMAP.md`
- `docs/CHANGELOG.md`
- `docs/DECISIONS_LOG.md`
- `docs/SECURITY_GUIDELINES.md`
- `docs/TESTING_STRATEGY.md`
- `docs/MCA_REPORT_NOTES.md`

## Review Areas

Score each area 1-10:

- Architecture readiness.
- Database readiness.
- Security readiness.
- Tenant isolation readiness.
- Module readiness.
- Testing readiness.
- Documentation readiness.
- MCA readiness.
- Repository readiness.

## Gate Decision

Choose exactly one:

- READY
- READY WITH MINOR IMPROVEMENTS
- REQUIRES REMEDIATION
- NOT READY

## Required Output

Provide:

- Scorecard.
- Overall score.
- Blocking issues.
- Non-blocking improvements.
- Required next task from the roadmap.
- Final verdict: YES or NO.
