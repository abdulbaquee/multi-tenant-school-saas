Audit only. Do not modify files.

Review documentation for consistency with implementation, prompts, roadmap status, and governance.

## Review Criteria

Verify:

- Phase status consistency.
- Roadmap alignment.
- Database and ERD consistency.
- Module and permission consistency.
- Screen flow and menu consistency.
- Security policy consistency.
- Testing strategy consistency.
- Changelog completeness.
- Decision log completeness.
- No stale "create this document" references for existing documents.

## Required Output

Provide:

- Documentation Score: 1-10.
- Contradictions.
- Stale references.
- Missing updates.
- Required docs to update.
- Recommendation: Approve, Approve With Minor Changes, Requires Documentation Pass, or Reject.
